bay1cg logo kit (Crown & Ember)

Lettering is converted to outlines, so no fonts are needed to open these files.
Fonts used: Cormorant Garamond SemiBold (BAY1), Jost Medium (CONSULTING GROUP).

Which file to use
- Website header, dark background ........ bay1cg-logo-horizontal-on-dark
- Documents, invoices, light background ... bay1cg-logo-horizontal-on-light
- Square spaces, slides, signage .......... bay1cg-logo-stacked-on-dark / -on-light
- One-color printing, embroidery .......... bay1cg-logo-horizontal-mono-ivory / -mono-midnight
- Favicon, app icon, watermark ............ bay1cg-mark-ember / -ivory / -midnight
- Facebook, Instagram, LinkedIn avatars ... bay1cg-avatar-midnight (recommended), -ivory, -ember

SVG = scalable (web, print, sign shops). PNG = transparent background, ready to drop in.

Colors
Midnight  #0E1626   Harbor     #1B2740
Ivory     #F5EFE3   Parchment  #E6DCC8
Brass     #B8935A   Brass deep #8A6A35
Ember     #E8531E

Rules: keep clear space equal to the height of the B's top stripe on all sides. No drop shadows,
no stretching, no recoloring the mark outside these colors.
